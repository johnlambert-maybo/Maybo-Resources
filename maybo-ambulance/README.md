# Maybo Ambulance Sales Page

A responsive, standalone sales page for Maybo's ambulance-sector offer.

## Upload to GitHub

1. Create a new repository.
2. Upload `index.html` and the `assets` folder, preserving the folder structure.
3. Enable GitHub Pages in **Settings → Pages**.
4. Publish from the repository root.

The Maybo logo is used exactly as supplied and is not recoloured, filtered or altered.

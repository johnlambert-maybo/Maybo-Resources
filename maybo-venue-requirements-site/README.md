# Maybo Venue Requirements Website

This folder is ready to publish with GitHub Pages.

## Publish using GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save the settings.

GitHub will provide the published website address after deployment.

## Included files

- `index.html` — the complete self-contained webpage
- `.nojekyll` — prevents unnecessary Jekyll processing
- `README.md` — deployment instructions

The webpage includes a link to the full Maybo Venue Requirements document for trainers.

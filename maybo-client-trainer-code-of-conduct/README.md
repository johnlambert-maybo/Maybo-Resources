# Maybo Client-Based Trainer Code of Conduct

GitHub Pages-ready webpage for the Maybo Client-Based Trainer Code of Conduct.

## Publish in the Maybo-Resources repository

1. Upload this complete folder to the repository root.
2. Keep the folder name as `maybo-client-trainer-code-of-conduct`.
3. Commit the files.
4. The page will be available at:

   `https://johnlambert-maybo.github.io/Maybo-Resources/maybo-client-trainer-code-of-conduct/`

## Files

- `index.html` — webpage
- `assets/maybo-logo.png` — approved Maybo logo supplied for this page

The trainer declaration button opens an email to `info@maybo.com` with the declaration wording pre-populated.

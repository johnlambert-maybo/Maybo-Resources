# Maybo Open PALMS™ resource

A self-contained, responsive HTML resource based on Maybo's Open PALMS™ ThoughtSpace article.

## Package contents

- `index.html` — page structure and content
- `styles.css` — responsive Maybo-branded styling
- `script.js` — accessible tabs, checklist, mobile menu and reveal effects
- `assets/maybo-logo.png` — supplied Maybo logo

## Add to an existing GitHub repository

1. Copy the `maybo-open-palms-resource` folder into the repository.
2. Commit the files.
3. Serve the folder through the repository's existing web stack or GitHub Pages.
4. The entry point is `index.html`.

No build step or package installation is required.

## External services

The package uses:
- Google Fonts for Lato
- YouTube's privacy-enhanced embed domain
- Links to Maybo's website

For a fully offline deployment, self-host the chosen font and video thumbnail/embed alternative.

## Accessibility and behaviour

- Semantic landmarks and headings
- Keyboard-operable tab interface
- Reduced-motion support
- Visible focus and skip link
- Responsive layouts
- YouTube iframe has an accessible title

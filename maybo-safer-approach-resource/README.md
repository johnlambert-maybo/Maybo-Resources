# Maybo SAFER Approach resource

A responsive, interactive HTML resource based on Maybo's published ThoughtSpace article, **Explaining Maybo's SAFER Approach**.

## Folder contents

- `index.html` — page structure and content
- `styles.css` — responsive Maybo-branded styling
- `script.js` — accessible tabs, checklist, mobile navigation and reveal effects
- `assets/maybo-logo.png` — Maybo logo

## GitHub Pages deployment

Copy the `maybo-safer-approach-resource` folder into the root of the existing repository.

The public URL will normally be:

`https://<username>.github.io/<repository>/maybo-safer-approach-resource/`

The folder must contain `index.html` directly at its top level.

## External resources

- Google Fonts: Lato
- YouTube privacy-enhanced embed
- Maybo ThoughtSpace hero image served from maybo.com

For a fully self-hosted deployment, download the article image with the appropriate permission and update the `.hero-image` URL in `styles.css`.

## Accessibility

- Semantic landmarks and heading hierarchy
- Keyboard-operable tab interface
- Reduced-motion support
- Skip link
- Responsive design
- Accessible iframe title

## Content note

This is an introductory resource. It does not replace Maybo training, organisational procedures, risk assessments or emergency guidance.
